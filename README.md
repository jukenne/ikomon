# いこモン

カードバトルRPG。カードオタクの「いこあん」が、カードを武器に世界を冒険して魔王に挑む。
ブラウザで動く（インストール不要）。PC のキーボード＋マウスで遊ぶ想定。

## あそびかた
- **移動**: 矢印キー / WASD（Shift 長押しでダッシュ）
- **話す・調べる・決定**: Z / Enter / Space
- **メニュー**: Tab（Esc でも可）… デッキ編集・クラスチェンジ・クエスト・どうぐ・セーブ
- **戦闘**: カードをドラッグして、上に離すと「使う」、別のカードの上に離すと「融合」。
  キーボードなら矢印キー + Z（決定） / X（戻る）
- **効果音の ON/OFF**: M キー

## セーブについて
自動セーブです。データは**遊んでいるブラウザの中**に保存されます。
別のブラウザや別のパソコンでは引き継げません。ブラウザの「サイトデータの削除」をすると消えます。

## 遊びかたのヒント
- 草むらを歩くと敵が出ます。勝つとおかねとカードの画像データが手に入ります。
- 強い敵に勝てないときは、クラスチェンジ（C キー）やデッキ編集を試してみてください。
